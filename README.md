# BlogApp Project

---

## 🇬🇧 English

###  Project Overview
BlogApp is a web application developed using ASP.NET technologies.  
The main goal of this project is to build a modern, scalable blog platform while learning important backend development concepts and architectural patterns.

Throughout this project, the following topics and techniques are covered:

###  Features and Topics Learned

#### 🔹 Seed Database Usage
- Learned how to use Seed Database to automatically add initial data to the database.
- Test data can be added without manually re-entering information after schema changes.
- Provides easier testing and faster development workflow.

#### 🔹 Database Providers
- Implemented support for different database providers such as:
  - MySQL  
  - MSSQL  
- Learned how to configure and switch between providers in ASP.NET projects.

#### 🔹 Repository Pattern
- Used Repository Pattern to organize database queries.
- Provides a clean and maintainable structure for data access.
- Improves scalability and code readability as the project grows.

#### 🔹 CRUD Operations
- Implemented full CRUD functionality:
  - Create
  - Read
  - Update
  - Delete  
- Used user-friendly URLs and structured routing.

#### 🔹 User Authentication & Comments
- Designed login and user registration pages.
- Users can add comments to posts.
- ASP.NET Identity concepts are integrated into the project.

#### 🔹 Home Page Post Display
- Only approved posts are shown on the home page.
- Posts are displayed with their related tags.
- Clicking on a tag lists all posts related to that tag.

#### 🔹 User Profiles
- Each user has a profile page.
- Profiles display:
  - Published posts
  - User comments

#### 🔹 Admin Authorization
- Different authorization levels for admin users.
- Admins can manage:
  - Posts  
  - Users  
  - Comments  
- Role-based access control implemented.
